# PITBREAK V2.6 — DROP 001 Product Media

## Approved media roles

Each DROP 001 collectible uses two real product views:

1. **FRONT** — retail packaging with the display light switched on. Used as the primary storefront image on the homepage, collection cards and product detail pages.
2. **BACK** — rear packaging view. Used as the second image in the product detail gallery.

## Storefront presentation

- Homepage hero: three-product DROP 001 photography grid.
- Collection and homepage product cards: FRONT image only.
- Product detail gallery: FRONT / BACK controls with an explicit selected-view label.
- Product photography remains visually dominant; PITBREAK framing stays black, white and neutral.
- Product-card labels use restrained contrast panels so packaging artwork remains readable.

## Commerce status

Pricing, inventory, shipping rates/services and checkout remain inactive until they are confirmed. The six destination countries shown on the site are planned test markets, not shipping commitments.

## Image delivery

The repository currently uses browser-validated JPEG assets for functional and responsive testing. Higher-resolution production exports should replace them before the final public sales launch without changing the existing image paths.
